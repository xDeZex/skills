# Spec lens

For each scenario in scope, quote it, then check which of these applies:

- **Missing or partial** — the scenario isn't satisfied, or only part of it is. A scenario that's satisfied but has no corresponding test is also a gap — flag it here.
- **Scope creep** — behavior in the diff that no scenario asked for.
- **Wrong implementation** — the scenario looks satisfied but the implementation doesn't actually do what it describes.

A finding with no scenario quoted is not a Spec finding.
