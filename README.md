# skills

My personal collection of AI skills, installable via [skills.sh](https://skills.sh).

## Install

```sh
npx skills add xDeZex/skills
```

## Skills

| Skill | Description |
|---|---|
| `impl` | Implementation skill for shorter tasks — investigates silently, presents a crisp summary, then implements |
| `implement-ticket` | Implement a to-tickets ticket end to end — RED/GREEN per acceptance criterion, a checkpoint commit per criterion, then a final review/fix loop |
| `parallel-issues` | Work on multiple tasks simultaneously with isolated background agents, one per task |
| `code-review` | Review the current diff |
| `openspec-schema-spec-driven-tdd` | Install the TDD-focused `spec-driven-tdd` schema into a project (RED → GREEN → REVIEW, no refactor step) |
| `c4-diagram` | Create and refine C4 architecture diagrams using PlantUML — renders via Kroki, visually inspects, and iterates until clean |
